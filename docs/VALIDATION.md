# 2.2.0 验证记录

验证日期：2026-09-14。环境：Windows 11（build 26200），Python 3.8.10 x64 / Tk 8.6.9（构建与测试）、Python 3.11 / Tk 8.6.12（测试），PyInstaller 5.13.2。

## 本次改动（2.2.0）

- 界面位图：`tools/make_assets.py` 以 4 倍超采样绘制并按 1x / 1.5x / 2x 三种倍率输出到 `assets/`（共 144 个 PNG）：14 种彩色分类图标 + 跳过占位图标、勾选框三态、5 个导航图标（普通 / 高亮两色）、3 个统计卡片图标、按钮与输入框九宫格（普通 / 悬停 / 按下 / 禁用 / 聚焦 / 只读）、侧边栏标志。`docs/assets_preview.png` 为 1x 资源对照图。
- 文件列表：首列改为 Treeview 的 `#0` 列，显示「勾选框 + 分类图标 + 文件名」复合位图（运行时用 `photo copy` 拼合，无需 Pillow）；去掉展开指示器占位；只在勾选框区域点击才切换选中。分类列与目标列显示去掉 emoji 前缀的分类名。
- 分类规则：列表显示彩色图标；编辑对话框加入 14 图标选择器，选择结果以 emoji 写入配置 `icon` 字段；旧配置按 emoji / 名称前缀自动匹配，未知图标回退为「其他」。
- 圆角控件：按钮、输入框、下拉框改为 `ttk` 图片元素（九宫格）。发现并解决的性能问题：ttk 对可拉伸区域逐块调用 `Tk_RedrawImage`（约 0.3 ms / 块），初版 20 px 小图导致首屏绘制 10.9 s；改为中段加宽（按钮 80 px、宽输入框 212 px、窄输入框 52 px）且高度等于控件自然高度后，首屏 0.6 s，页面切换 30–60 ms。
- 其他：设置页复选框改用绘制的勾选框位图；侧边导航图标 + 高亮条；资源缺失时全部退回文字样式；版本号 2.2.0；`build.py` 打包 `assets/` 目录并在缺少资源时提前报错。
